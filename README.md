Ce dépôt rassemble les réalisations, l'analyse technique et les livrables produits durant mon **stage technique de 3ème année** au sein de l'entreprise **PRESAT**. Cette expérience combine le déploiement d'infrastructures de télécommunication physiques et le développement d'une visibilité numérique pour l'entreprise.

---

## 🏗️ Architecture & Topologie Réseau Déployée

Durant ce stage, j'ai participé à la mise en place d'une architecture réseau isolée pour garantir la sécurité des flux de l'entreprise :
* **Segment WAN** : Connexion internet haut débit via une parabole et un modem satellite **Tooway** (Zone blanche).
* **Segment LAN Local** : Déploiement d'un switch managé configuré avec des **VLANs** dédiés pour séparer les ordinateurs administratifs des flux vidéo des caméras IP afin d'éviter la saturation du réseau professionnel.

📂 **[Voir l'exemple de script de configuration de switch réseau déployé dans ce projet](./switch-config.cfg)**

## 🛠️ Missions & Réalisations Techniques

### 1. 🌐 Télécommunications & Déploiement Réseau
* **Configuration Internet Satellite (Tooway)** : Installation de paraboles, pointage vers le satellite, câblage coaxial et configuration de modems pour fournir une connectivité haut débit.
* **Architecture Réseau Local (LAN)** : Sertissage de câbles réseau RJ45, raccordement sur switchs/routeurs et configuration de répéteurs Wi-Fi pour étendre la couverture réseau.

### 2. 🛡️ Sécurité & Vidéosurveillance
* **Systèmes de Vidéosurveillance IP/Analogique** : Installation physique de caméras de sécurité, raccordement à un enregistreur (DVR/NVR) et configuration logicielle des masques de détection de mouvement.
* **Paramétrage des Accès Distants** : Configuration des redirections de ports (*Port Forwarding*) sur les routeurs pour permettre le visionnage sécurisé des flux vidéo en direct depuis l'extérieur.

### 3. 💻 Solutions Web & Communication
* **Conception d'un Site Vitrine (Wix)** : Création d'une plateforme web moderne et responsive pour mettre en valeur les services de l'entreprise, optimisée pour le référencement local (SEO).
